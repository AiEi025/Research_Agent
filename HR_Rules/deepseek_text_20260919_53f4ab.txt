Access card.
Company mobile phone if required.

Through a ticket in the IT system (support.arianatech.ir).

11.3 PERSONAL USE
Limited personal use is allowed.
Installing unauthorized software is prohibited.
Personal commercial use is prohibited.

Ticket at support.arianatech.ir.
Phone: extension 1500.

Sharing passwords is prohibited.
Lock the screen when leaving the desk.

Limited personal use is allowed.
Large file downloads: restricted.
Content filtering: per regulations.

11.7 SOFTWARE
